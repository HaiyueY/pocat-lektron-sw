# ADCS 轨道与环境模型（S3）— pocat-lektron-sw

> 状态：S3 完成 · 2026-10-14（目标板 DWT 周期数待硬件）
> 关联：`docs/adcs_integration_roadmap.md` §3 S3，`docs/adcs_resource_budget.md` S3 节

本文说明星上参考矢量（位置、速度、nadir、地磁场、太阳方向）的模型、接口、验证结果、误差预算，以及 IGRF 阶数的权衡结论。

---

## 1. 模块与接口

所有文件放在 `src/subsystems/adcs/` 与 `include/subsystems/adcs/`（固件 CMake 只 glob 一层目录）。模块内没有 `malloc`、`printf` 和可变全局量，状态都由调用方持有。

| 模块 | 作用 | 关键接口 |
|------|------|---------|
| `adcs_time` | Unix ↔ JD、日历 → Unix、十进制年、TLE 历元、GMST（IAU-82） | `adcs_time_gmst(unix_s)` |
| `adcs_tle` | 定列 TLE 解析（不用 `strtod`）、两行校验和、行号/卫星号/范围检查；出错时不改写输出 | `adcs_tle_parse(l1, l2, &tle)` |
| `adcs_sgp4` | Vallado 版近地 SGP4（WGS-72），记录只读、可重入；深空（周期 ≥ 225 min）拒绝 | `adcs_sgp4_init()`、`adcs_sgp4_propagate()` |
| `adcs_igrf` | IGRF-14（2025.0 主场 n ≤ 13 + SV n ≤ 8），阶数为运行时参数，栈占用与阶数无关 | `adcs_igrf_field_ecef(r, year, n, &b)` |
| `adcs_sun` | 天文年历低精度太阳方向 + 圆柱阴影 | `adcs_sun_direction()`、`adcs_eclipse_cylindrical()` |
| `adcs_ephemeris` | 集成层：一次调用得到全部参考矢量与状态位 | 见下 |
| `adcs_bench`（仅 `ADCS_BENCH`） | 目标板 DWT 计时 | `./build.sh --adcs-bench` |

IGRF 系数与 Legendre 递推常数由 `scripts/adcs/gen_igrf14_coeffs.py` 从 NCEI 的 `igrf14coeffs.txt` 生成，生成的头文件里记录了来源 URL 和 SHA-256。

### 1.1 集成层（S4a 的调用方式）

```c
static adcs_orbit_t orbit;              /* S4a：静态分配；adcs_orbit_init() 一次 */

/* 新 TLE（S5 上传后由 N_ADCS_NEW_TLE 触发）：解析 + 初始化 + 历元试传播全部通过才提交 */
adcs_orbit_load_tle(&orbit, line1, line2);      /* 失败则保留旧 TLE */

/* 每个控制周期，在 adcs_mode_step() 之前 */
adcs_ephem_t eph;
adcs_ephem_update(&orbit, (double)time_get_unix(), ADCS_IGRF_ORDER, &eph);
adcs_ephem_to_state(&eph, &state);              /* 只有有效时才拷贝 */
```

`eph.status` 状态位只报告情况，不做决策，模式策略由 S4a 的任务层决定：

| 位 | 含义 | 输出是否可用 |
|----|------|-------------|
| `ADCS_EPH_NO_TLE` | 还没有接受过任何 TLE | 否 |
| `ADCS_EPH_SGP4_ERROR` | SGP4 报错（`eph.sgp4_error`，Vallado 码 1/2/4/6） | 否 |
| `ADCS_EPH_IGRF_ERROR` | 磁场无法计算（位置异常） | 否 |
| `ADCS_EPH_TLE_STALE` | \|TLE 年龄\| > `ADCS_TLE_MAX_AGE_S`（14 天） | 是，精度下降 |
| `ADCS_EPH_IGRF_EXTRAPOLATED` | 日期超出 IGRF-14 的 2025–2030 区间 | 是，精度下降 |

`ADCS_EPH_INVALID_MASK` 是前三位之和。

### 1.2 时间

- 输入为 UTC 的 Unix 秒（`double`），UT1 取作 UTC。
- **ADCS 不判断系统时间是否有效。** 时间有效性由 OBC/OBDH 负责（2026-10-14 决定）；ADCS 直接使用 `time_get_unix()` 的值。
- TLE 年龄是 TLE 数据自身的属性，以 `tle_age_s` 和 `ADCS_EPH_TLE_STALE` 上报（供 S5 的 beacon 使用）。
- SGP4 的 `tsince` 用两个 Unix 秒之差计算，不用两个 JD 相减，以保留双精度分辨率。

## 2. 坐标系约定

**所有参考矢量都在 TEME 中表达**，`adcs_state_t` 中各 `*_eci` 字段实际存放的是 TEME 矢量。

| 量 | 计算方式 |
|----|---------|
| 位置 / 速度 | SGP4 直接输出 TEME |
| 地固系 | r_ecef = R3(GMST) · r_teme（伪地固系，忽略极移） |
| 地磁场 | 在地固系中按地心球坐标计算 IGRF，再用 R3(−GMST) 转回 TEME |
| 太阳方向 | 平赤道历元坐标（MOD），与 TEME 相差 < 0.005°，直接作为 TEME 使用 |
| nadir | −r̂ |

所有参考矢量共用一个坐标系，因此 TEME 与 J2000 之间约 0.37°（2027 年的岁差量）的差**不影响**姿态解。只有当以后出现需要 J2000 的消费者时（例如地面指令的惯性指向）才需要转换。

## 4. 误差预算（星上参考矢量）

| 来源 | 量级 | 说明 |
|------|------|------|
| IGRF 截断（n = 7） | 方向 0.25°（95%），最大 0.60°；\|B\| 0.43%（95%） | §5，450–550 km SSO 统计 |
| IGRF 模型与真实场之差（地壳场、外源场） | 平静时约 0.1°；磁暴时高纬地区可达 1–2° | 量级估计，未建模 |
| TLE 老化（SGP4 + 根数误差） | 典型增长 1–3 km/天；14 天约 40 km → nadir 约 0.3°，B 方向约 0.7° | 与阻力有关，入轨后用真实 TLE 历史标定 |
| 时间分辨率（`time_get_unix()` 为整秒） | ≤ 1 s → nadir ≤ 0.06°，B ≤ 0.13° | S4 可改用 RTC 亚秒寄存器 |
| UT1 − UTC（< 0.9 s） | 地球自转角 < 0.004° → B ≤ 0.004° | 忽略 |
| 极移 | < 0.5″ | 忽略 |
| 太阳星历 | 0.01°（实测 0.0092°，含光行差） | — |
| MOD 与 TEME 之差（太阳） | < 0.005° | — |
| 圆柱阴影 vs 锥形阴影 | 进出影时刻偏差为秒级（半影约 8–10 s） | 仅用于与 CSS 交叉校验 |
| TEME vs J2000 | 约 0.37° | 坐标系统一，对姿态无影响 |

合计以 IGRF 截断与 TLE 老化为主，最坏也在 1° 量级，远小于 20° 的 APE 要求。

## 5. IGRF 阶数权衡

**预设决策规则**（写在研究之前）：取满足以下两条的最小阶数 N：

1. 方向误差的 95 分位 ≤ 0.5°；
2. 闭环 APE 指标与 N = 13 相比无显著差异。

### 5.1 开环（`test/test_igrf_order.c`）

设计 SSO 根数在 450 / 500 / 550 km 各传播 4 段 24 h（TLE 历元 + 0 / 91 / 182 / 273 天），步长 10 s，共 103 680 点，与 N = 13 的场比较。

|---|------|---------|---------|---------|----------|---------------|
| 1 | 2 | 8.76° | 20.88° | 35.77° | 48.9% | 0.07 |
| 2 | 5 | 5.28° | 11.32° | 20.48° | 20.4% | 0.11 |
| 3 | 9 | 2.40° | 4.87° | 7.36° | 9.6% | 0.15 |
| 4 | 14 | 1.00° | 2.22° | 4.72° | 3.9% | 0.21 |
| 5 | 20 | 0.46° | 1.10° | 1.75° | 1.6% | 0.27 |
| 6 | 27 | 0.27° | 0.55° | 1.03° | 1.1% | 0.34 |
| **7** | **35** | **0.11°** | **0.25°** | **0.60°** | **0.43%** | **0.41** |

在 500 km 处，倾斜偶极（N = 1）的方向误差达到 21°（95%）。原因是非偶极项约占场强的 22%（RMS，由 Lowes 谱估算）。旧仿真的真值与星上都用倾斜偶极子，所以暴露不出这项误差。

主机耗时在 `-O0` 下测得，只用来比较各阶的相对开销。目标板上软双精度的开销同样与项数近似成正比（§6）。

### 5.2 闭环（`test/sweep_igrf_order.sh`）

### 5.3 结论

**`ADCS_IGRF_ORDER = 7`**（`adcs_config.h`）。

- 开环：N = 6 的 95 分位为 0.55°，不满足规则；N = 7 为 0.25°，是满足规则的最小阶数。
- 闭环：N ≥ 5 与 N = 13 已无显著差异；N = 7 的 ΔAPE 为 0，末轨均值之差（+0.13 ± 0.13°）在噪声以内。
- 开销：N = 7 计算 104 项中的 35 项。

如果 S4b 的实测 CPU 时间显示仍有余量，可以再评估 N = 8。

## 7. 仿真：真值与星上分离

`test/sim/sim_environment.c` 中有两套环境：

- `sim_env_init()`：沿用旧模型（400 km 圆极轨道、倾斜偶极子、太阳固定在 +X），S1 的 5 项回归输出逐位不变。
- `sim_env_init_ephem()`：真值环境，使用设计 TLE（500 km SSO，LTDN 10:30，历元 2027-09-15，合成根数）、IGRF-14 n = 13、随时间运动的太阳和圆柱阴影。

`test_nadir --ephem` 中，传感器与动力学由真值驱动，控制器的参考矢量来自 `adcs_ephem_update(ADCS_IGRF_ORDER)`，与星上一致。真值与星上共用 SGP4、太阳和阴影模型，只有 IGRF 阶数不同；其余误差源按 §4 单独评估。

`ctest` 中的 `nadir_ephem`（N = 7）：APE 99.06%，末轨均值 3.28°，通过。

### 7.1 发现：阴影中开始 nadir 时，首次“捕获”是偶然的（交给 S4a）

在 §5.2 的 10 个工况中，有 4 个在首次捕获之后又离开了 20° 带（峰值 24°、33°、52°、69°，APE 低至 95.2%），其余 6 个始终没有离开。这几个工况在 N = 7 与 N = 13 下几乎相同（峰值相差 < 0.1°，APE 相差 < 0.02 pp），所以与 IGRF 阶数无关。

这几个工况的共同点是：仿真开始时卫星就在阴影中，首次捕获也发生在阴影中，之后立刻出现偏离。原因是 `nadir_init()` 把姿态估计置为单位四元数，而在第一次有日照的 TRIAD 之前，估计只由陀螺从这个任意初值传播而来，此时测得的“捕获”没有意义。旧环境总是从日照区开始，所以没有暴露这个问题。

S4a 的建议：

- 进入 nadir（或开始统计 APE）之前，先等待第一次有效 TRIAD；
- 在阴影中收到 NADIR 请求时，保持 IDLE 或 DETUMBLING，直到出影。

S3 不修改控制器。

## 8. 留给后续阶段

- **S4a：**
  - 每个周期先调用 `adcs_ephem_update()` 再调用 `adcs_mode_step()`；`adcs_orbit_t` 静态分配。
  - 根据状态位制定策略，例如 `TLE_STALE` 或输出无效时转到 IDLE。
  - 处理 §7.1 的入口条件。
  - `determination_update()` 的阴影分支使用 `b_field_eci_prev`，但这个字段从未被更新（只在 `nadir_init()` 中清零）。目前 `nadir_step()` 只在有日照时调用该函数，所以这个分支不可达；S4a 需要补上更新或删除这个分支。
- **S4b：** 用 `./build.sh --adcs-bench` 实测周期数与栈水位，更新预算表；必要时降低参考矢量的更新频率（例如 10 s 更新一次并插值），而不是降低精度。
- **S5：**
  - `TC_UPLOAD_ADCS_TLE` 直接调用 `adcs_orbit_load_tle()`（失败时保留旧 TLE）；
  - beacon 字段使用 `tle_age_s` 与 `eph.status`。
